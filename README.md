# MOPS 資安重訊監控系統

## 專案說明

本 Repository 由自動化監控系統每日更新，追蹤台灣公開資訊觀測站（MOPS）上公開發行以上公司發布的資訊安全相關重大訊息。

## 報表位置

每日報表存放於 reports/ 資料夾，格式為 YYYY-MM-DD-isec-report.md。

## 資料來源

- 台灣證券交易所公開資訊觀測站: https://mops.twse.com.tw/mops/web/index

## 監控關鍵字

資訊安全、資安事件、遭駭、個資外洩、勒索病毒、網路攻擊等
